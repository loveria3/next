📚 공부계획 프롬프트

처음 프롬프트로 계획을 만들고, 수정 프롬프트로 상황 변화에 맞게 이어서 고쳐 봐요
처음
나는 중학교 2학년인데, 지난번 영어 성적이 75점이었어. 1학기 기말시험 에는 좋은 성적을 받고 싶은데 하루에 몇 시간을 공부해야 하는지, 또 어떤 것을 위주로 공부를 해야 하는지 한 달 치 공부 스케줄을 만들어 줘
수정
이번 주에 국어 수행평가도 갑자기 생겼어. 국어도 같이 준비해야 할 것 같은데, 두 과목을 하루 1시간 안에 어떻게 나눠서 공부하면 좋을지 계획을 다시 짜줘
💡 상황이 바뀌면 새 대화 말고 같은 창에서 이어서 계획을 다시 짜 달라고 해요!

🧳 여행계획 프롬프트

처음 프롬프트로 일정을 만들고, 수정 프롬프트로 이어서 고쳐 봐요
처음
기말시험이 끝났어. 친구 둘과 함께 내가 있는 제주에서 가까운 곳으로 하루 일정으로 놀러 가고 싶어. 각자 쓸 수 있는 돈은 3만 원 정도인데 여행 스케줄을 만들어 줘
수정
제주는 너무 많이 가봐서 서귀포에 가보고 싶어. 서귀포 일정으로 만들어 줘.
💡 답이 마음에 안 들면 새 대화 말고 같은 창에서 이어서 고쳐요!

🎮 숫자게임 프롬프트

처음 프롬프트로 게임을 만들고, 수정 프롬프트로 디자인을 입혀 봐요
처음
웹페이지로 1~100 사이 숫자 맞추기 게임을 만들고 싶어. 사용자가 기회 5번 만에 못 맞추면 패배 문구를 띄워 주고, 매 단계마다 업다운(Up/Down) 힌트를 줘야 해.
수정
웹페이지에 디자인을 입히고 싶어. 깔끔하고 심플한 애플 스타일의 페이지로 수정해 줘.
💡 뭉뚱그려 부탁하면 엉성하게, 처음 → 수정으로 구체적으로 이어 부탁하면 훨씬 좋게 나와요!

💡 아이디어 프롬프트

우리 팀이 가진 부품으로 만들 수 있는 프로젝트 아이디어 3개를 추천받아요
너는 중학생 눈높이에 맞춰 아두이노 피지컬 컴퓨팅 프로젝트를 기획해주는 선생님이야. [상황] 우리는 해안 지역의 문제를 해결하는 프로젝트를 하고 있어. [우리가 가진 부품] - 두뇌 : 아두이노 나노 (USB 케이블, 미니 브레드보드, 점퍼 전선 포함) - 출력 : 서보 모터(움직임), 피에조 버저(소리), LCD(정보 표시), RGB LED(빛) - 입력 : 택트 스위치(버튼) - 센서 : 수위 센서(물의 깊이), 진동 센서, 컬러 센서, 비접촉 온도 센서, 온습도 센서 [조건] 1. 센서 1~2개 + 출력 장치 1~2개만 써서 회로가 복잡하지 않게 (브레드보드에서 중학생이 직접 연결 가능한 수준으로) 2. "OO을 알아채면 → XX해 주는 기계" 형식으로 작동 원리를 3단계 이내로 쉽게 설명 3. '임계값', '트리거' 같은 전문 용어 대신 "기준이 되는 숫자" 처럼 쉬운 말로 풀어서 설명 4. 실제 바닷가가 아니라 교실에서 시연·테스트해야 해. 수위 센서를 쓴다면 종이컵이나 작은 그릇에 물을 붓는 정도로만 테스트할 수 있는 아이디어로 제안하고, 큰 물통이나 실제 바닷물이 필요한 시나리오는 제외해줘. [요청] 위 부품만으로 실제로 만들 수 있는 해안 지역 문제 해결 아이디어를 3개 제안해줘. 아이디어마다 아래 항목을 채워줘. - 이름 (재미있는 이름) - 해결하는 문제 (한 문장) - 사용하는 센서·출력 장치 - 작동 원리 ("OO을 알아채면 → XX해 주는 기계" 형식) - 교실 테스트 방법 (물이나 열 등을 어떻게 안전하고 간단하게 재현할 수 있는지) - 목표 (이 프로젝트를 통한 해안 지역 문제 해결 목표) - 난이도 (하/중/상) 난이도 '하'인 것부터 순서대로 보여줘.

🔍 검토용 프롬프트

후보 아이디어가 좋은 아이디어인지 3가지 기준으로 점검받아요
너는 중학생 아두이노 프로젝트를 검토해주는 선생님이야. [우리 팀 후보 아이디어] - 이름 : (아이디어 이름) - 해결하는 문제 : (한 문장) - 사용하는 센서·출력 장치 : (센서와 출력 장치) - 작동 원리 : (OO을 알아채면 → XX해 주는 기계) - 교실 테스트 방법 : (물이나 열 등을 어떻게 재현하는지) - 목표 : (이 프로젝트를 통한 해안 지역 문제 해결 목표) [검토 기준] 아래 3가지 기준으로 이 아이디어를 평가해줘. 1. 우리 지역의 진짜 문제를 해결하는가? 2. 우리가 가진 센서·부품만으로 구현이 가능한가? (추가 부품이 필요하면 무엇인지도 알려줘) 3. 팀원 모두가 흥미를 느낄 만한 주제인가? (팀장·하드웨어·소프트웨어·디자이너·데이터 분석가 역할이 골고루 참여할 수 있는가) [요청] 1. 각 기준마다 O/△/X로 평가하고, 이유를 한 문장으로 설명해줘. 2. △나 X가 있으면, 우리가 가진 부품 안에서 바로 고칠 수 있는 구체적인 수정 방법을 1~2가지 제안해줘. 3. 이 아이디어를 그대로 만든다면 필요한 센서·출력 장치와 대략적인 연결 순서(어떤 핀에 무엇을 연결하는지까지는 아니어도 됨)를 간단히 알려줘. 단, 최종 결정은 AI가 아니라 우리 팀이 하는 거니까 정답을 정해주지 말고, 참고할 수 있게 제안해줘.
